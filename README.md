# stackof20 Homebrew tap

Official tap for stackof20. Apple silicon (M1 or later), macOS 15 or later.

```sh
brew tap stackof20/tap && brew trust --cask stackof20/tap/stackof20 && brew install --cask stackof20/tap/stackof20
```

Requires current Homebrew. The trust entry applies only to this cask. Uninstalling the app does not remove your mail, saved replies, snoozes, settings or license.

The cask is automatically synchronized from verified, signed stable GitHub releases every 15 minutes. No app source code is stored here.

Support: https://stackof20.com/support.html
